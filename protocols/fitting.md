# FIT01 / FIT02 开发任务卡 v1

两题均为项目自建的合成开发数据，不是实测传感器数据或保留题评测。文件在 `examples/fitting/`。

| 项目 | FIT01 calibration | FIT02 curve |
|---|---|---|
| 目标 | 带截距线性标定 | 训练内五折交叉验证选1–5阶 |
| 数据生成 | y=2+3x+ε | y=1−2x+0.7x²+ε |
| 随机数 | NumPy default_rng(42) | NumPy default_rng(43) |
| 噪声 | ε~N(0,0.08²) | ε~N(0,0.08²) |
| x | linspace(-2,2,60) | linspace(-2,2,60) |
| 单位 | x伏，y摄氏度 | x/y无量纲 |
| 划分 | 从0开始行号 i%4==1 为test，其余train | 同左 |

每题45个训练点、15个留出点。CSV 是固定资产；不得因为结果不佳重分留出集。数据留出与题族保留测试是两个层次：这两道题始终属于开发集。

模型 y=Σc[k]z^k，z=(x−center)/scale，center/scale 只由当前训练数据计算。每个交叉验证折重新估计归一化参数。五折排列种子20261016；候选比较用所有验证残差汇总RMSE，绝对差≤1e-10时选较低阶。最后在全部训练集重拟合，测试集仅用于最终误差。

人工模型见 calibration_model.json / curve_model.json。原始多项式基下的独立复算位于 evaluation/fitting.py，预测、RMSE、MAE 容差1e-8。线性闭式解另有回归测试。已知生成函数用于说明来源，不要求含噪估计系数等于真值。自动选阶不能保证所有带噪数据都选中真阶数。

常见错误：把测试标签参与拟合或选阶、无截距替代有截距、用高阶训练误差宣称泛化更好、隐瞒外推、把合成数据当真实业务验证。最少10条训练/2条测试；不同x不足或矩阵秩不足时拒绝；仅限独立观测的一元普通最小二乘，时间序列、分组、鲁棒拟合暂不支持。
