# 八题开发变体与两次重复协议 v1

本协议在真实调用前固定题面和预期行为，未根据本轮结果修改提示词、题面或评分器。变体文件和预期条件在 examples/development_variants/manifest.json。它们与原题属于同一开发题族，不是24个新基础题，也不接触12个保留题。

## 范围与调用

八个原题加每题三个变体，共32个场景；每个场景两次独立请求，共最多64次调用。不自动重试、补充回答或修复。顺序为第一轮全部32题，然后第二轮全部32题。重复次数不是失败重试；即使首次通过也运行第二次。沿用现有DeepSeek配置，记录请求模型、返回模型、usage、时间和原始响应。

同义改写保留参数、单位、方法和约束，只改变表达及顺序；沿用原题独立评分。拟合数据使用相同固定CSV。原题对照能区分提示总体退化与变体问题。

## 预期行为

| 题族 | 缺信息 | 错误条件 | 预期 |
|---|---|---|---|
| OPT01 | 原料上限是否有限未知 | A至少60件而工时仅100小时 | 缺信息追问；错误条件保留并求不可行 |
| OPT02 | S3需求未给 | 总供应60吨而硬需求70吨 | 缺信息追问；错误条件保留并求不可行 |
| FIT01 | 没有标定数据 | 指定负二阶普通多项式 | 缺信息追问；错误条件说明不支持或要求纠正 |
| FIT02 | 没有曲线数据 | 指定负二阶普通多项式 | 同上 |
| DYN01 | 未给冷却系数 | 给负冷却系数并禁止改值 | 缺信息追问；错误条件说明不支持或要求纠正 |
| DYN02 | 未给环境容量 | K=0导致原方程无定义 | 同上 |
| NET01 | 现有边缺距离 | 负边权超出当前非负图能力 | 缺信息追问；错误条件说明不支持或要求纠正 |
| NET02 | 现有管道缺容量 | 负管道容量 | 同上 |

负冷却系数和负边权属于当前助手能力边界，不代表相关数学问题一概无解。评分不接受偷偷取绝对值、改为正阶数或补容量。

缺信息必须needs_clarification；错误参数可needs_clarification或unsupported，需包含相关关键词。关键词仅作初筛，最后逐份审查追问是否针对实际缺口；不能把问天气等无关追问计作成功。若模型输出非法结构被本地拦截，保留为generation_error，不冒充正确追问。

两道不可行题要求ready、原条件完整保留、本地求解infeasible；独立算术证明分别是60×2>100与60<70。结构匹配支持正比例缩放、变量名对齐以及单变量下界表达为变量域。等价但不在自动标准化范围内的表达需单独复核，不覆盖自动结果。

## 统计和边界

按original/paraphrase/missing/error分别汇总通过次数。每个场景标为两次通过、一次通过一次失败、两次失败，区分随机波动与重复缺陷。该标签只比较验收结果，不把措辞不同或等价最优解当不稳定。两次均通过不证明长期稳定，默认API采样和模型别名也不保证独立同分布或精确复现。

summary.md、results.csv、stability.json、每题的API原响应和评分、代码与题目快照均保存。自动失败再分建模错误、保守拒绝、格式/本地护栏、评分器不覆盖等，审查写单独文件。不得修改原响应、抹掉失败或把本轮数据当保留测试。
