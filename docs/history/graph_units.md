# 图边权程序换算与89场景开发回归

助手v0.11.0，DeepSeek deepseek-flash，协议v4。此次完成图原始参数输入、逐边程序换算、审计展示与边界测试，并执行一次完整真实API回归。历史v0.10.11批次及path_units失败未修改或补跑覆盖。

## 实现与范围

在线图输入为graph_input，逐边weight保留原数值、unit保留原文单位写法，source_quote保存边端点与数值引用，unit_quote保存边单位或公共单位声明。顶层unit只指定输出单位。程序使用Fraction精确计算换算因子，长度包括mm/cm/m/km与列明别名；流量包括升/立方米每秒、分钟、小时、天的斜杠写法。其他相同单位可原样传递，未知混合单位和量纲不兼容不猜测转换。

在线旧graph输入会被拦截，不能绕过原值来源；人工旧graph文件兼容已统一单位流程。人工graph_input可离线换算但无原题文本时不核对引用。最大流换算后必须为整数，禁止截断和四舍五入。负值、非有限值、超范围值拒绝执行。

source_model.json保留原值、单位、引用；unit_conversion.json记录原值、目标值、逐边有理数因子。model.json供求解，中文报告同时展示原值和换算结果。原始API响应不改变。正常单位换算与数值求解属于正常流程，不计本地修复；本地停止或追问计local_guard。

运行时引用检查是有限词法检查：验证连续逐字引用、端点、数值和单位出现，不等同于任意自然语言的边/单位归属证明。公共单位声明的写法检查仍较严格，图引用不做自动修复。

## 本地测试

146项测试全部通过，较此前134项新增12个测试方法（部分含多组边界）。覆盖混合单位、反向换算、科学计数法、零边权、原值/引用不变、米/千米子串误匹配、未知与不兼容量纲、全局单位声明、最大流整数与非整数换算、负数/非有限数/布尔值/上限、空图/零流/重复边、在线旧格式拦截、原始与格式修复分类，以及独立审计器拒绝被篡改因子。

7个本地CSV检查另行通过，不计API次数。测试日志保存在批次local_tests.log。

## 保留的失败与本地处理

最终两项失败：

- NET02_paraphrase：模型将各边记录与位于句末的公共单位说明拼成source_quote，不再是连续原文。程序拒绝执行，完整题被转成追问。该拦截避免了未经核对的输入，但没有完成用户任务，仍记失败。后续应改进分离提取边引用与公共单位引用，不放宽为允许随意拼接。
- immutable_permission：原题允许修改参数但要求先询问，模型直接unsupported。属于既有动态追问能力的波动，未在本轮修改或补跑。

5项本地接管通过：DYN02_error、immutable_lock_keep、equivalent_exponent_difference、graph_units_unknown、graph_units_fractional_flow。因此不能声称大模型本身已经解决这些问题。
