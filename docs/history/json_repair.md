## 修复规则

仅当顶层model_type与model.task_type完全相同，且仅删除该字段后整个响应符合schema，才执行一次本地删除。重复信息不影响数学模型；不会改数值、单位、约束、任务类型、status或questions，不调用模型二次修复，也不重试API。

以下仍拒绝：类型冲突、其他未知顶层字段、模型内部额外参数、缺字段、值类型错误、截断响应或非法JSON。数学参数错误不能靠格式修复通过，仍进入现有参数校验/追问流程。例如K=0保持为0，不自动改为正数。

格式修复记录包含规则版本、动作、删除路径和原值、修复前后规范化JSON的SHA256、修复后的结构以及数学参数校验是否通过。哈希针对规范化JSON内容，不声称是原始HTTP字节流哈希。原始API响应保存在generation.response，保持不变。

成功运行目录的format_repair.json独立记录上述内容；报告标注是否经过本地修复。批量调用即使修复被拒绝也在api.json保留原响应及拒绝原因。原始schema通过、本地修复后通过、原题数值通过分开统计。
