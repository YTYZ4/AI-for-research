# 否定表达、隐含冲突与合法换算误拒绝修复

当前助手v0.11.5。否定及隐含冲突误接管已修正并通过历史重放和定向测试；合法单位换算的提示修复仍未稳定有效，不能宣布全部修复完成。本次没有重跑完整101场景，不覆盖既有失败。

## 实现与边界

- 改值建议检查按有界分句识别“不请求、不要求、不要、不能”等否定；保留双重否定、转折后新请求、裸改值建议的拦截。协调否定“不能取绝对值或改为正数”可保留。
- 冲突追问可使用“两条/处/份记录，请核对哪条准确”等表述，无需出现固定“冲突”关键词。仍需列出所有冲突原值、处于追问状态、model为空；拒绝预选值、正值引导、否认冲突、缺值和把初值冒充容量值。
- 明确程序支持精确转换后校验整数，原始小数可能换算为整数；输出单位声明不是第二条容量记录。在线仍保留原始边权、单位及逐字引用，由程序做实际换算。没有将unsupported强行改成ready，没有删除非整数及未知换算护栏。
- 运行时与评价器分别实现响应检查，以预先标注的正反例核对。两者仍属于有界词法检查，不能声称完整语义验证或独立人工评分。

196项本地测试通过（上轮187项，新增9个测试方法，包含多组子案例）。包括否定/实际建议成对测试、冲突误放行控制、合法正向与反向换算、同单位小数、未知单位拒绝、旧错误拒绝不被自动改写。

## 离线重放与统计说明

主批离线16项全部符合预期：旧4条误接管原样放行；旧11条实际错误仍接管；旧合法换算错误拒绝原样保留失败。补批再重放主批4条词法误接管，均原样保留且独立检查通过。均为零API，不能加入在线分母。

三个通过数都是累计口径，不能相加。原始包含生成前参数提取和提示，排除生成后格式/引用修复及接管；正常确定性换算不算修复。本轮修正语义检查以接受等价表达，因此与旧规则的比例不能直接归因于模型改善。两批不合并成一个新版通过率，不改写旧自动结果；本次共87次付费请求，453,519 tokens。

仍需推进：合法换算的模型拒绝决策与实际程序能力分离、空拒绝说明、单位引用边界。后续应先验证可审计的程序能力检查方案，而不是继续堆叠提示或直接把拒绝响应改为模型。
