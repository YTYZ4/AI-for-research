## 已交付

- 同一 CLI 支持自由文本 + CSV，经 DeepSeek 生成受限模型规格、本地拟合、留出验证、逐点残差导出。
- `--data` 接受固定 x,y,split CSV。CSV 内容不会由程序发给模型；API仅接收题面、表头和行数。若用户把数值写进题面，该部分仍会发送。
- 数据快照和原文件 SHA256 留在 run.json；报告说明归一化系数的解释、单位、误差、候选阶数。可用 model.json 配合相同 CSV 离线复算。
- 自动选择仅在训练集内五折进行；增加留出误差差距与外推提示，提示不等同于统计证明。
- 37 项自动测试通过，覆盖旧优化入口、精确多项式、闭式线性复算、留出标签修改不影响系数或选阶、非法CSV、退化数据、报告导出。
