# 图与网络求解报告

S到T最短路径

任务：shortest_path；起点：S；终点：T；单位：km。
所有边按有向边解释；双向道路须在模型中列出两个方向。
假设：所有边均为有向边，只能沿给定方向行驶。；距离统一为千米（km），1千米=1000米；原始4000米=4千米，2千米=2千米，1000米=1千米，5000米=5千米，3千米=3千米，7千米=7千米。；没有其他道路。；最短路径问题仅支持非负权重。

| 起点 | 终点 | 距离或容量 |
|---|---|---:|
| S | A | 4000 |
| S | B | 2 |
| B | A | 1000 |
| A | C | 2 |
| B | C | 5000 |
| C | T | 3 |
| A | T | 7 |

状态：optimal；结果：1007 km。
路径：S → B → A → C → T
距离标签（null为不可达）：{'S': 0, 'A': 1002, 'B': 2, 'C': 1004, 'T': 1007}

验证：{'passed': True, 'checks': {'reachable_set_closed': True, 'distance_inequalities': True, 'path_matches_distance': True}}

证据只针对生成的图；仍须对照原题核对方向、缺边、权重与单位。当前不支持负权、平行边、多商品流或成本流。
