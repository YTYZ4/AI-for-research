# 图引用与先询问修改许可定向回归v1

助手v0.11.1，12个固定开发场景各3次，共36次真实DeepSeek调用，无重试。两个旧失败使用原题；图组含公共单位位于前/后、逐边单位、长度混合与流量混合；动态组含明确许可、同义表达、合法参数、禁止修改、容量缺失、容量冲突及超出任务范围对照。全部是已有题族开发变体，不是保留新题。

运行前冻结代码、测试、题面、评分器、协议及历史重放来源。图题独立原图/容量/流量评分并检查原值、单位和换算审计。图引用修复只有在程序独立提取出的全部有向边、数值、单一全局单位与模型一致时才可改变引用字段；审计验证原响应完整、数学字段不变、替换为逐字原文、修改清单一致。其成功计local_source_repair，不计格式或原始成功。

允许修改但要求先询问的K<=0题，必须needs_clarification并询问用户确认或提供正实数容量，不得自行执行替代值或直接unsupported。合法参数须ready；缺容量只补缺失信息；冲突先中立核对；禁止改值和不支持任务不得错误触发许可策略。评价包含部分关键词检查，另做只读定性复核，不冒充完整语义证明或独立人工评审。

原始通过、格式修复后累计、本地处理后累计分开。格式修复不改变数学内容；本地层另含引用修复和响应接管。正常单位换算仍计正常流程。分类优先级local_guard > local_source_repair > format_repair > native。历史失败重放零API，单独计数；不修改旧批次、不补跑覆盖失败，不与旧完整89场景合并比例。
